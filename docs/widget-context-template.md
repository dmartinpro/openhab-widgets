# Widget context template

Copy this file into a new widget's folder as `context.md` and fill it in.

## Purpose

What this widget displays/controls, and why it exists (e.g. "compact card
for a heating zone: setpoint, current temp, mode toggle").

## Items / Groups used

- `Item_Name` — role (e.g. state, setpoint, switch)
- `Group_Name` — role

## Config parameters

List any `props`/`config` the widget expects when instantiated (name, type,
default, description).

## Layout notes

Anything non-obvious about the flexbox structure, breakpoints, or visual
states (e.g. "row collapses to column under X width", "color reflects
`item.state` via `oh-repeat` on thresholds").

## Known issues / TODO

Open problems, workarounds in place, or follow-ups.
